## 三、证型权重引擎（syndrome_weight_engine.py）

- 输入：批1指标(名称+等级+方向) + 批2舌诊/面诊量化 + 模块2症状0-10分
- 输出：八证型 score/percent/排序 + **逐条证据审计**（每条含教材依据，
  即"为什么判你脾虚"的可解释来源，直接喂前端展示与模块6解释引擎）
- 安全位：证据不足不出结论；寒热并重/灰黑苔/肾功能异常→强制人审；
  50条规则独立成RULES表，供中医师逐条校准不动代码
- 自测：阳虚脾虚/肝胆湿热/血瘀三画像 top1 全中（37%/72%/90%）

## 四、诚实缺口记录

1. herb_prop 只覆盖131味（06中药图谱本身小且偏罕用药）——**常用药四气
   五味归经缺口**，第4批补：从chp_qa文本抽取 + 物色中药属性数据集。
2. 古方6,521条组成中仅452条现代克数，其余为两/钱/铢等古制——已存
   数量+单位+原文，折算由第4批剂量引擎按方源年代查dose_convert处理。
3. NMPA名录只有成份无剂量（做"收录证明"举证够用，不做剂量参考）。
4. 证型规则权重与批1/批2一样是v1启发式，needs_clinical_calibration。

## 五、第4批预告（核心算法层）

0.1g精准组方引擎：证型占比(本批)×指标权重(批1)×KB剂量统计(本批
chp/古方两套)×dose_convert×风控规则(孕妇儿童/肝肾/过敏/黑名单)。
配套需要两个**新数据源**（下批给精确采购清单）：①卫健委药食同源目录
（102种，官方公开）②毒性药材黑名单（药典"有毒/大毒"标注）。
